### 🔬 01. Belle II — Constrained Optimization & Data Reconstruction

**Scientific Computing · Large-Scale Data · Numerical Optimization**

[**View Repository →**](https://github.com/HaoWangOct/belle2-constrained-optimization)

Research project investigating constrained optimization techniques for tau-decay reconstruction at the Belle II experiment.

- Processed more than **2.8 million real and Monte Carlo events**
- Worked with large-scale particle physics datasets using Python, C++ and the Belle II framework
- Investigated constrained fitting, track parameters, covariance matrices and kinematic constraints
